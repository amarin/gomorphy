# Этап 8. Поиск лемм FT5 — ВЫПОЛНЕН

## Содержание этапа

Инкремент: `Lemmas(word)` → начальная форма + разборы.

- Реализация поверх postings; значения через арены. Полная грамматическая
  характеристика собирается из леммы + формы: `Snapshot.LemmaAncodes` (секция
  `lemmas.ancodes`, format v2), `Wordform.Grammemes`/`Ancode` — объединённый разбор,
  `LemmaRef` получил базовые граммемы леммы.
- Семантика выдачи зафиксирована сверкой с эталоном:
  - `AddLemma` создаёт якорную пару «цитата → голый базовый анкод» для
    резолва начальных форм через `Lemmas()`; `Lookup` такие пары не выдаёт
    (citationPair-фильтр) — чтением словарной статьи они не являются;
  - пара, разделяемая несколькими леммами, разворачивается в `Lookup` в
    отдельное чтение на каждую лемму — омонимичные разборы различимы,
    даже когда наборы тегов совпадают («соляное»: 2 пары / 4 разбора).

## Проверка (выполнена)

- unit-тесты: слова-омонимы («стекла», «пила») → ≥2 леммы; уникальное
  слово → 1; слитый разбор «кота» = `NOUN,anim,masc,sing,gent`.
- сверка с эталоном: 100 случайных словоформ из 3 065 312 против
  независимого двухпроходного разбора `dict.xml`
  (`pkg/dictionary/reference_integration_test.go`): плотные id лемм, полные
  граммемы и число разборов совпали полностью.
