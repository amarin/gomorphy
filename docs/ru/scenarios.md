## 1. Морфологический разбор слова

**Задача.** Получить все грамматические разборы словоформы: часть речи,
падеж, число, род, начальную форму.

**Как.** `Dictionary.Parse(word)` возвращает `[]Reading` (`Word`, `Normal`,
`Tag`, `Prob`, …). Ввод приводится к нижнему регистру. Разборы словаря из
pymorphy2 отсортированы по вероятности (`Prob`); у остальных источников
`Prob == 0`. Из командной строки: `gomorphy lookup -d <словарь.dat> <слово>`.

```go
d, err := morphology.Open(".data/pymorphy/pymorphy.dat")
// ...
for _, r := range d.Parse("стали") {
    fmt.Println(r.Normal, r.Tag, r.Prob)
}
```

В словаре pymorphy2 и в собранном через `Builder`/`ImportTSV` (или слитом
на такую базу) незнакомое слово тоже получит разборы — угаданные по
окончанию; см. [сценарий 3](#3-отличить-словарное-слово-от-догадки). У
импортов OpenCorpora и UniMorph предсказания нет: для незнакомого слова
`Parse` возвращает `nil`.

**Доступно с:** 1.0.0.

**История изменений:**
- 1.2.0 — угаданные разборы помечены `Reading.Predicted`; CLI `lookup`
  выводит рядом с ними `(predicted)`.

## 2. Приведение к лемме для поиска и индексации

**Задача.** Свести «кота», «котом», «коты» к одному ключу «кот» — для
поискового индекса, подсчёта слов или сопоставления запроса с текстом.

**Как.** `Dictionary.Lemma(word)` возвращает по одному `LemmaRef` на
омоним (`Normal` и собственный тег леммы `Tag`). Несколько результатов —
слово неоднозначно («стали» → «сталь» и «стать»): индексируйте все или
выбирайте по `Tag`. CLI: `gomorphy lemmas`.

```go
for _, l := range d.Lemma("кота") {
    fmt.Println(l.Normal) // кот
}
```

**Доступно с:** 1.0.0.

**История изменений:**
- 1.2.0 — `LemmaRef.Predicted` равно true, если все разборы за леммой
  угаданы; пропускайте такие леммы, если в индексе должны быть только
  словарные слова.

## 3. Отличить словарное слово от догадки

**Задача.** Узнать, действительно ли слово есть в словаре. `Parse` угадывает
разборы незнакомых слов по окончанию, и угаданный разбор выглядит как
любой другой — в маленьком словаре «разбирается» почти всё. (Речь о словарях с
предсказанием: pymorphy2 и собранных через `Builder`/`ImportTSV`.)

**Как.** `Dictionary.IsKnown(word)` — только точный поиск, без
предсказания (нижний регистр и `CharPolicy` применяются, как в `Parse`).
Либо смотрите `Reading.Predicted` / `LemmaRef.Predicted` в уже полученных
результатах. `MultiDictionary.IsKnown` истинно, если слово знает хотя бы
один словарь набора.

```go
d.IsKnown("кота")               // true
d.IsKnown("бота")               // false
d.Parse("бота")[0].Predicted    // true — догадка
```

**Пример:** [ner](../../examples/ner/main.go), `ExampleDictionary_IsKnown`.

**Доступно с:** 1.2.0. До 1.2.0 отличить догадку от словарного разбора
было нельзя.

## 4. Поиск именованных сущностей по словарю

**Задача.** Находить в тексте известные имена (людей, мест, организаций,
товаров) в любой грамматической форме: «в Москве», «памятник Пушкина».

**Как.** Соберите словарь имён через `Builder` (или `ImportTSV` —
[сценарий 5](#5-тематический-словарь-из-tsv)): каждая форма с леммой и
собственным тегом типа сущности (`GEO`, `PERSON`, …; теги — произвольные
строки). Дальше для каждого токена: `IsKnown` говорит, имя ли это, `Parse`
даёт лемму и тег. Слова при сборке приводятся к нижнему регистру, поэтому
«Москве» из текста находит сохранённое «москве». Чтобы искать имена и
обычные слова вместе, объедините оба словаря в `MultiDictionary`
([сценарий 7](#7-несколько-словарей-одновременно)) и смотрите
`Reading.Dict` — какой словарь ответил.

```go
b := morphology.NewBuilder(morphology.BuilderOptions{Language: "ru", Source: "names"})
b.AddForm("Москве", "Москва", "GEO,loct")
names, err := b.Build()
// ...
if names.IsKnown(token) {
    r := names.Parse(token)[0] // r.Normal == "москва", r.Tag == "GEO,loct"
}
```

**Пример:** [ner](../../examples/ner/main.go).

**Доступно с:** 1.1.0 (`Builder`); надёжно — с 1.2.0.

**История изменений:**
- 1.2.0 — добавлены `IsKnown` и `Predicted`: раньше крошечный словарь имён
  «узнавал» почти любое слово через предсказание по окончанию.
- 1.2.0 — `Builder`/`ImportTSV` приводят слова и леммы к нижнему регистру.
  Имя, добавленное как «Москва» в 1.1.0, находилось только как догадка.
  **Словари имён, собранные 1.1.0 из данных с заглавными буквами, нужно
  пересобрать.**

## 5. Тематический словарь из TSV

**Задача.** Собрать словарь своей лексики — терминов предметной области,
имён, сленга — без интернета и без базового словаря.

**Как.** Подготовьте строки `лемма<TAB>словоформа[<TAB>теги]`, затем
`gomorphy import tsv words.tsv -o words.dat` или
`morphology.ImportTSV(r, BuilderOptions{Language: "ru"})`. Пустые строки и
комментарии `#` пропускаются; пустая лемма делает словоформу собственной
леммой; предсказание строится по вашим же словам. Результат сохраняется и
открывается через `SaveTo`/`Open`, как любой словарь.

```
# лемма	словоформа	теги
фрегат	фрегат	NOUN,nomn
фрегат	фрегата	NOUN,gent
```

**Пример:** [importtsv](../../examples/importtsv/main.go),
`ExampleImportTSV`; CLI: [cli.md](cli.md), команда `import`.

**Доступно с:** 1.1.0.

**История изменений:**
- 1.1.0 — строка с пустой словоформой — ошибка (раньше молча принималась).
- 1.2.0 — колонки словоформы и леммы приводятся к нижнему регистру; TSV-словари,
  собранные 1.1.0 из данных со смешанным регистром, нужно пересобрать.
- 1.2.0 — замена е→ё по умолчанию действует только для `Language` "ru"
  (см. [сценарий 9](#9-её-и-другие-замены-символов)).
- 1.2.1 — поток без записей — ошибка (`ErrNoEntries`), как у `Builder`;
  раньше получался пустой словарь.

## 6. Дополнить или переопределить базовый словарь

**Задача.** Добавить недостающие слова в полный словарь (pymorphy2,
OpenCorpora) или заменить неверные разборы — и получить один `.dat`.

**Как.** `morphology.Merge(base, overlays, MergeAdd)` добавляет слова
оверлея, которых нет в базе; `MergeReplace` заменяет существующие разборы
слова разборами из оверлея (побеждает последний оверлей). CLI: `gomorphy
merge --mode add|replace -o merged.dat base.dat overlay.dat`. База
сохраняет свои парадигмы, имя набора тегов (так что `tagmap` продолжает
работать), вероятности и предсказание. Вариант без слияния в один файл —
[сценарий 7](#7-несколько-словарей-одновременно).

**Пример:** [merge](../../examples/merge/main.go), `ExampleMerge`,
`ExampleMergeWithOptions`.

**Доступно с:** 1.1.0.

**История изменений:**
- 1.1.0 — слияние структурное (этап 19.1): первые версии возможности
  пересобирали результат с нуля и теряли предсказание, вероятности и имя
  набора тегов.

## 7. Несколько словарей одновременно

**Задача.** Использовать базовый словарь и свои дополнения вместе, не
сливая их в один файл: например, чтобы обновлять их независимо или знать,
из какого словаря пришёл разбор.

**Как.** `morphology.NewMultiDictionary(d1, d2, …)` поверх уже открытых
словарей. `Parse`/`Lemma`/`Fuzzy` склеивают результаты словарей в порядке
регистрации; `Reading.Dict` (а также `LemmaRef.Dict`, `FuzzyMatch.Dict`) —
номер словаря в наборе. CLI: несколько флагов `-d`.

**Пример:** [multidict](../../examples/multidict/main.go),
`ExampleNewMultiDictionary`.

**Доступно с:** 1.0.0.

**История изменений:**
- 1.2.0 — `MultiDictionary.IsKnown`.

## 8. Опечатки и подсказки

**Задача.** Понять, что имел в виду пользователь: «кто» → «кот»,
подсказки при опечатках, нестрогий поиск.

**Как.** `Fuzzy(word, maxDist)` возвращает все слова словаря на расстоянии
Левенштейна не больше `maxDist` (в рунах); `FuzzyTop(word, n)` — `n`
ближайших слов, расширяя расстояние по мере надобности. Оба результата
отсортированы по (расстояние, слово). CLI: `gomorphy fuzzy`, `gomorphy top`.

```go
d.Fuzzy("кот", 1)     // кот 0, кит 1, код 1, …
d.Fuzzy("Елка", 0)    // ёлка 0
d.FuzzyTop("катк", 2) // 2 ближайших слова
```

**Пример:** [typos](../../examples/typos/main.go),
`ExampleDictionary_Fuzzy`, `ExampleDictionary_FuzzyTop`.

**Доступно с:** 1.0.0.

**История изменений:**
- 1.2.0 — запрос приводится к нижнему регистру: заглавная буква больше не
  стоит правки (раньше «Кот» не совпадал с «кот» на расстоянии 0).
- 1.2.0 — применяется `CharPolicy` словаря: для русского «е» в запросе
  совпадает с «ё» в словаре на расстоянии 0 (было 1). Пороги, подобранные
  под старую метрику, может понадобиться поправить.

## 9. е/ё и другие замены символов

**Задача.** Находить «ёлка», когда в тексте написано «елка» — в русских
текстах точки над ё обычно опускают, — или задать похожие соответствия
для другого алфавита.

**Как.** `CharPolicy` словаря — список односторонних замен: руна запроса
`From` совпадает также с руной словаря `To`. Для русского по умолчанию
е→ё: «елка» находит «ёлка», но «ёлка» не находит «елка». Политика хранится
в словаре и используется в `Parse`, `Lemma`, `IsKnown`, `Fuzzy` и
`FuzzyTop`. Задаётся при сборке: `BuilderOptions.CharPolicy` или
`UniMorphOptions.CharPolicy` — `RussianCharPolicy()`, `NoCharPolicy()` или
`NewCharPolicy(Substitution{From: 'е', To: 'ё'}, …)` (не больше 255 замен).

```go
opts := morphology.BuilderOptions{
    Language:   "ru",
    CharPolicy: morphology.NoCharPolicy(), // е и ё — разные буквы
}
```

**Пример:** `ExampleNewCharPolicy`, `ExampleNoCharPolicy`.

**Доступно с:** 1.2.0 (публичный API; русские словари применяли е→ё и
раньше, но изменить это было нельзя).

**История изменений:**
- 1.2.0 — `CharPolicy == nil` означает «по языку»: е→ё для "ru" и для
  пустого `Language`, ничего для других языков (раньше е→ё получал любой
  собранный словарь).
- 1.2.0 — больше 255 замен — ошибка при сборке (раньше — паника позже, в
  `SaveTo`).

## 10. Словарь для другого языка

**Задача.** Использовать поиск, леммы и нечёткий поиск gomorphy для
другого языка.

**Как.** Соберите словарь сами через `Builder` или `ImportTSV`
([сценарий 5](#5-тематический-словарь-из-tsv)) и укажите
`BuilderOptions.Language` (например, "uk"). Русская замена е→ё не
применяется; если языку нужны свои замены, передайте `CharPolicy`
([сценарий 9](#9-её-и-другие-замены-символов)). Импортёр UniMorph пока
принимает только `Language: "ru"`. `Merge` требует у всех входов один и
тот же язык.

**Доступно с:** 1.1.0.

**История изменений:**
- 1.2.0 — нерусские словари больше не получают е→ё по умолчанию.

## 11. Словарь внутри бинарника; Windows

**Задача.** Распространять один исполняемый файл со словарём внутри — без
файла данных рядом, — или работать на Windows, где `Open` (mmap) не
поддерживается.

**Как.** Встройте `.dat` через `//go:embed` и откройте его
`morphology.OpenBytes(data)`: тот же формат и та же проверка контрольной
суммы, что у `Open`, но без mmap и без копирования `data` (срез должен жить
не меньше словаря; переменная уровня пакета подходит). `Close` ничего не
делает.

```go
//go:embed names.dat
var namesDat []byte

d, err := morphology.OpenBytes(namesDat)
```

**Пример:** [embed](../../examples/embed/main.go), `ExampleOpenBytes`.

**Доступно с:** 1.2.0.

## 12. Кэширование по содержимому словаря

**Задача.** Кэшировать что-то, вычисленное по словарю (производный индекс,
результаты запросов), и сбрасывать кэш только тогда, когда действительно
меняются слова — а не при каждой пересборке или пересохранении.

**Как.** `Dictionary.ContentHash()` — хэш содержательных секций без секции
`info` (время сборки, версия библиотеки, источник): он не меняется при
`SaveTo`/`Open`/`OpenBytes` и при пересборке из тех же данных. Зато он
зависит от кодирования: те же слова с другим алфавитом или `CharPolicy`
дают другой хэш. Первый вызов вычисляет хэш, дальше он берётся из кэша.

**Пример:** [contenthash](../../examples/contenthash/main.go),
`ExampleDictionary_ContentHash`.

**Доступно с:** 1.2.0.

## 13. Сравнение тегов разных словарей

**Задача.** Разборы из разных источников описывают одну и ту же форму в
разной нотации: OpenCorpora `NOUN,anim,masc,sing,gent`, UniMorph
`N;GEN;SG`. Их нужно сравнить — например, проверить, что два словаря
согласны в падеже и числе.

**Как.** `tagmap.Map(d.TagSetName(), reading.Tag)` приводит тег источника
к набору признаков UniMorph; сравнивайте наборы целиком или по отдельным
измерениям (`tagmap.DimCase`, `tagmap.DimNumber`, …), если один источник
размечает признаки, которых нет у другого. `tagmap.Known(name)` говорит,
можно ли вообще нормализовать набор тегов (словарь из `Builder` со своими
тегами — нельзя).

**Пример:** [tagmap](../../examples/tagmap/main.go), `tagmap.ExampleMap`,
`ExampleMultiDictionary_DictTagSetName`.

**Доступно с:** 1.0.0.

**История изменений:**
- 1.1.0 — `tagmap.Known`.

## 14. Ручная проверка словаря

**Задача.** Заглянуть в словарь при сборке или отладке: как разбирается
слово, настоящая ли это словарная запись, какой словарь ответил.

**Как.** `gomorphy lookup`/`lemmas`/`fuzzy`/`top -d <словарь.dat> <слово>`
или интерактивная консоль `gomorphy cli -d <словарь.dat>`. Несколько `-d`
опрашивают несколько словарей; колонка `para#<dict>/…` показывает, какой
ответил. См. [cli.md](cli.md).

**Доступно с:** 1.0.0.

**История изменений:**
- 1.2.0 — `lookup` добавляет в строку угаданного разбора дополнительную
  колонку `(predicted)`.

## 15. Загрузка исходных словарей из Go-кода

**Задача.** Скачивать и распаковывать исходные данные pymorphy2,
OpenCorpora или UniMorph из своей программы — так же, как это делают
`gomorphy download`/`unpack`.

**Как.** `pymorphy.NewLoader(dir)`, `opencorpora.NewLoader(dir)` или
`unimorph.NewLoader("ru", dir)`, затем `loader.Sync(false)`, затем сборка
из `loader.UnpackedDirPath()` / `UnpackedFilePath()` — см.
[library.md](library.md), раздел «Получение исходных данных».
`Sync(false)` проверяет, нет ли нового выпуска, и обновляет локальную
копию; `Sync(true)` работает без сети с тем, что уже на диске. Неудачная
загрузка сохраняет прежние данные. Загрузчикам не нужна настройка
логирования: без `logging.Init` они ничего не пишут в лог; чтобы
использовать свой логгер, присвойте экспортируемое поле `Logger`.

**Пример:** [pymorphy](../../examples/pymorphy/main.go) (читает уже
скачанный каталог).

**Доступно с:** 1.0.0.

**История изменений:**
- 1.2.1 — загрузчики больше не падают с паникой, если программа не
  вызывала `logging.Init` (его вызывал только CLI `gomorphy`).
- 1.2.1 — `Sync` распаковывает новую загрузку поверх старой копии (раньше
  оставались старые данные), файлы создаются в указанном каталоге (а не в
  `./.data`), скачивание атомарно и проверяет HTTP-статус, `Sync(true)` не
  обращается к сети.
